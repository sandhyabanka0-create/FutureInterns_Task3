\# Future Interns - Data Science \& Analytics Task 3



\## Marketing Funnel \& Conversion Performance Analysis



\### Project Overview



This project analyzes marketing campaign data to understand customer conversion performance.



The analysis focuses on:

\- Overall conversion rate

\- Drop-off rate

\- Contact channel performance

\- Job-wise conversion

\- Education-wise conversion

\- Housing loan comparison



\## Dataset



Dataset: Bank Marketing Dataset



Source:

UCI Machine Learning Repository



File used:

bank-full.csv



\## Tools Used



\- Python

\- Pandas

\- Matplotlib

\- PowerShell

\- VS Code



\## Key Results



\- Total contacts: 45,211

\- Converted customers: 5,289

\- Overall conversion rate: 11.70%

\- Drop-off rate: 88.30%



\## Contact Channel Conversion



\- Cellular: 14.92%

\- Telephone: 13.42%

\- Unknown: 4.07%



\## Job Conversion



The conversion rate varies across different job categories.



\- Student: 28.68%

\- Retired: 22.79%

\- Unemployed: 15.50%

\- Management: 13.76%

\- Blue-collar: 7.27%



\## Education Conversion



\- Tertiary: 15.01%

\- Unknown: 13.57%

\- Secondary: 10.56%

\- Primary: 8.63%



\## Housing Loan Conversion



\- No housing loan: 16.70%

\- Housing loan: 7.70%



\## Recommendations



1\. Monitor the large overall drop-off between contacted customers and conversions.

2\. Compare contact-channel performance when planning future campaigns.

3\. Segment campaigns by customer characteristics such as job and education.

4\. Investigate why some customer segments have lower conversion rates.

5\. Improve tracking of unknown contact information so campaign performance can be measured more clearly.
